# Launcher Changelog

## 2026.11.24.0

### Added
- The beta launcher now has a β badge.

### Changed
- Updated to .NET 10 and Avalonia 12.2.0.
- The beta launcher no longer uses orange, and looks the same as the standard launcher.
- If the launcher can't check for or download its own update, it now carries on and downloads the installer.
- The backup installer download link now uses HTTPS.
- The launcher's version now comes from its release tag.
